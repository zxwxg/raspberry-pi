What is it?

A full computer, the size of a credit card

Launched in 2012 to get more young people coding, the Raspberry Pi became one of the best-selling computers ever made in Britain. Today it's used everywhere — classrooms, factories, laboratories, TV streaming boxes, robots and data centres.

  • Runs real Linux. Raspberry Pi OS is built on Debian 13 “Trixie”, with a polished desktop and a friendly Control Centre.
  • Talks to the physical world. A 40-pin GPIO header and official HAT add-ons connect sensors, motors, cameras and displays.
  • Desktop-class I/O. Dual 4K displays, USB 3.0, Gigabit Ethernet, Wi-Fi, Bluetooth and (on Pi 5) PCIe for NVMe storage.
  • Backed by a huge ecosystem. Award-winning documentation, decades of tutorials and one of the friendliest maker communities anywhere.
  • From $5 to server-grade. The Pico 2 microcontroller starts at $5; the Pi 5 scales up to 16 GB of RAM.

Getting started

From box to blinking LED in an afternoon

Four steps, one microSD card and about 20 minutes of patience. Works for every model.

  1. Gather the essentials

    Your board, a quality power supply, a 16 GB+ microSD card and a case. A monitor, keyboard and mouse are optional — see step 3.

  2. Flash Raspberry Pi OS

    Install Raspberry Pi Imager on your computer, pick your board, and choose the latest Raspberry Pi OS (Debian 13 “Trixie”).

  3. Boot — with or without a screen

    Insert the card and power up. Going headless? Set Wi-Fi, hostname and SSH in Imager's settings before you write the card, then connect from any terminal.

  4. Update and start building

    Run the commands on the right, then install whatever your project needs — Docker, Kodi, Home Assistant, Python. The ecosystem does the rest.

pi@raspberrypi:~ 
# keep the system fresh
$ sudo apt update
$ sudo apt full-upgrade -y
$ sudo reboot

# then build something
$ sudo apt install -y docker.io python3-pip
$ python3 -m pip install gpiozero
$ raspi-config   # tweak interfaces & hardware
Terminal on Raspberry Pi OS — the same commands work over SSH.

Good to know

Frequently asked questions

How much does a Raspberry Pi cost?

The Pico 2 microcontroller starts at $5, the Zero 2 W is $15 and the flagship Pi 5 starts at $45 (1 GB model). Higher-memory models have become noticeably more expensive because of the global LPDDR4 memory shortage in 2025–26 — check the official store for today's prices.

Do I need a monitor, keyboard and mouse?

No. Raspberry Pi Imager lets you pre-configure Wi-Fi and enable SSH before you even insert the card, so you can run it “headless” and control it from any terminal on your network. For desktop work, any HDMI display, USB keyboard and mouse will do.

What operating system does it run?

Most models run Raspberry Pi OS, now based on Debian 13 “Trixie”, with a full desktop or a Lite command-line image. You can also install Ubuntu, LibreELEC, RetroPie, Home Assistant OS and many others. The Pico is different — it has no operating system and runs C/C++ or MicroPython firmware directly.

Can a Raspberry Pi run Windows?

Not officially — it's a Linux-first platform, and that's where the best experience is. Community projects have booted Windows on ARM in experimental ways, but they're unsupported and not recommended for daily use.

What's the difference between Raspberry Pi and Raspberry Pi Pico?

Raspberry Pi (like the Pi 5) is a full single-board computer: it runs an operating system, drives displays and networks, and behaves like a small PC. Pico is a microcontroller: no OS, boots instantly, draws very little power and is designed for real-time control of electronics. Many projects use both together.

Is it a good way to learn programming?

It was designed for exactly that. The Raspberry Pi Foundation provides free learning resources, and the board ships with Python, Scratch and built-in editors. Because it can also control real hardware, it's often the moment coding clicks for beginners of any age.
